# EventHub

Full-stack Event Management and Booking Application.

## Technologies

Frontend:
- React.js
- Bootstrap
- Axios
- React Router

Backend:
- Node.js
- Express.js
- JWT Authentication

Database:
- MySQL

## Features

- User Registration & Login
- JWT Authentication
- Event Management
- Event Details
- Event Image Upload
- Ticket Booking
- Quantity Selection
- Total Price Calculation
- REST API Integration
